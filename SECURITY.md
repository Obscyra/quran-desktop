# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private reporting instead:
**[Report a vulnerability](https://github.com/Obscyra/quran-desktop/security/advisories/new)**.

Include what you found, how to reproduce it and the version. You can expect a first reply within a week.

## Supported versions

Only the latest release is supported. The app updates itself from the latest release (Settings → Updates).

## What the app does

- It has no accounts and sends no analytics.
- It contacts only the Quran.com API and its audio hosts (see the Privacy section of the README).
- Update packages are signed, and the app checks the signature before installing.
