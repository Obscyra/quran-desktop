# Surah frame sources

- madinah.svg: glyph extracted from the Tarteel QUL common font (https://qul.tarteel.ai/resources/font/459, ligature "header"), flipped and saved as one path. No licence is stated by the page or the font. Confirm redistribution terms with Tarteel before shipping.
- ottoman.svg: original drawing, modelled loosely on the sura heading structure of the Met Open Access Qur'an manuscript (object 453024). No traced pixels or paths. GPL-3.0 with the app.
- indopak.svg: original drawing (frame, star band, medallions, lattice). GPL-3.0 with the app.
